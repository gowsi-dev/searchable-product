# Searchable Product Catalogue
  A simple and interactive product catalogue built using HTML, Css, Javascript. It Search product based on name, price and rating.
## Features
- Product : Display products with name, images, price, rate.
- Category Filter : Filter products by Electronics, Home, Fashion category.
- Price Filter : Filter products by price
- Rate Filter : Filter products by rating.
## Technologies Used
- HTML
- CSS
- Javascript
## Concept Learned
- Javascript Array methods : filter(), map(), includes().
- Working with arrays of objects and nested arrays.
- Event handling using addEventListener().
- Handling checkbox states.
- Implementing multiple filtering conditions.
